# djinny-privacy

Public host for the [Djinny](https://github.com/Magwerste/djinny) app's privacy policy,
served via GitHub Pages so it has a stable public URL for the Play Console listing.

The source of truth for the policy content lives in the main (private) `djinny` repo at
`docs/privacy-policy.html` — copy changes over here (as `index.html`) when it's updated
there.

Live page: https://magwerste.github.io/djinny-privacy/
